Drive backup

Your phone copies its photos and videos into a Drive folder you choose, quietly in the background. It uses a small script that lives in your own Google account. About five minutes, once.

  1. 1

    Choose the Drive folder

    Open the folder in Google Drive, copy its address from the browser, and paste it here.

    That doesn’t look like a Drive folder address.

    Set the folder’s sharing to Restricted (only you). If anyone with the link can open it, anyone with the link can see your photos.

  2. 2

    Make the script

    Go to script.google.com, choose New project, delete the sample code, and paste this in.

    Paste the folder address in step 1 first.

    View the script 
    
        
    
        
    Your secret word (already inside the copied script). You will type it into the dashboard later.

        3
        
    Allow Drive access
    
        
    In the script editor open Project settings (the gear), tick Show “appsscript.json” manifest file in editor, go back to the editor, open appsscript.json, and replace everything in it with this.
    
        
        
    This lets your own script write into your folder. It is not shared with anyone else.
    
      
    4. 

      
  4. 
        4
        
    Publish it
    
        
    Click Deploy, New deployment, the gear, Web app. Run as Me, access Anyone, then Deploy. Google asks you to allow access. It warns that the app isn’t verified, because you wrote it: choose Advanced, then Go to … (unsafe), then Allow. Copy the Web app address that ends in /exec.
    
      
    5. 

      
  5. 
        5
        
    Tell the app
    
        
    On the phone: Features and passcode, switch on Backup to Google Drive and allow the permissions it asks for. On the computer: open Phone Link, go to Phone, find Backup to Google Drive, paste the web app address and the secret, and press Save.
    
        
    That’s all. From then on the phone copies new photos and videos by itself, newest first, whenever it is on Wi-Fi. It shows nothing and never deletes anything from Drive. To check on it, look in the Drive folder.
